# ScreenCheat

托盘小工具：开启后，截屏和录屏软件拿到的画面是纯黑，你自己看到和操作的仍是正常桌面。适合录屏时临时遮掉某一段。

## 用法

先按下面"构建"一节生成 `publish\ScreenCheat.exe`，再运行它（需要 .NET 10 桌面运行时）。程序只在系统托盘里显示一个显示器图标，**启动后防录屏默认就是开着的**。

| 操作 | 作用 |
|---|---|
| `Ctrl+Alt+F9` 或左键单击托盘图标 | 开关防录屏 |
| 右键托盘图标 → 遮挡范围 | 全部显示器，或勾选其中几块 |
| 右键 → 显示桌面宠物 | 默认勾选：开启时右下角出现一个敲代码的小黑客，关闭时消失 |
| 拖动宠物 / 右键宠物 | 左键拖到别处，位置会记住；右键弹出和托盘一样的菜单 |
| 右键 → 宠物回到右下角 | 拖动过才出现，清除记住的位置 |
| 右键 → 启动时自动开启 | 默认勾选；取消后，启动时防录屏是关着的 |
| 右键 → 修改热键… | 直接按下新组合键 |

命令行参数：

- `--on` / `--off`：
  - 程序已在运行时：让它开启或关闭，等屏幕上真正生效后才返回，返回后马上截图就是对的。退出码 0 表示成功。
  - 程序没在运行时：启动它，这次启动时开启或关闭，忽略"启动时自动开启"设置。此时会变成常驻程序，脚本里调用不要等它结束。
- `--status`：不改任何东西，只用退出码报告状态：1 = 开着，0 = 关着，2 = 没在运行。
- `--exit`：让正在运行的实例退出。

脚本或 AI 助手需要截屏时，可以先关、截完再开（PowerShell）：

```powershell
$sc = "$env:LOCALAPPDATA\Programs\ScreenCheat\ScreenCheat.exe"
$state = (Start-Process $sc '--status' -Wait -PassThru).ExitCode
if ($state -eq 1) { Start-Process $sc '--off' -Wait }
# ……截屏……
if ($state -eq 1) { Start-Process $sc '--on' -Wait }
```

设置保存在 `%AppData%\ScreenCheat\settings.json`。

## 安装（可选）

程序不需要安装，单个 exe 直接运行即可。想让它开机自动运行，可以这样做（只用到当前用户的目录，不需要管理员权限）：

- **放到固定位置**：把 `publish\ScreenCheat.exe` 拷到 `%LocalAppData%\Programs\ScreenCheat\`。以后重新编译时，不会因为程序正在运行、文件被占用而失败。
- **建快捷方式**：在开始菜单（`%AppData%\Microsoft\Windows\Start Menu\Programs`）和"启动"文件夹（同一目录下的 `Startup`）里各建一个指向它的快捷方式。
- **更新**：先在托盘菜单里点"退出"，或运行 `ScreenCheat.exe --exit`，再把新的 exe 拷过去覆盖。

## 原理

每块被选中的显示器上盖一层全屏窗口，这个窗口有三个特点：

- **对你透明**：用色键（color key）实现，你看到的就是下面的桌面。
- **鼠标穿透**：点击直接落到下面的窗口上。
- **截屏里是黑的**：窗口用 `SetWindowDisplayAffinity(WDA_MONITOR)` 打了标记，系统合成截图时会把这块区域换成黑色。

遮罩自己保持在最上层，不依赖你有没有动鼠标键盘：

- 别的程序弹出置顶窗口（菜单、提示框）或切换前台窗口时，遮罩立刻回到最上层。
- 另外每 30ms 检查一次遮罩上面有没有可见窗口，有就抬回去。这一条兜住"已经显示着的窗口自己设成置顶"这种不发事件的情况。
- 遮罩本身不接收焦点、点击和按键，你的操作全部落在下面的窗口上。

桌面宠物（`PetWindow` + `PetArt`）是一个逐像素透明的置顶小窗，约 15 帧/秒，动画全部由代码绘制，没有图片资源。它和遮罩一起被抬到其他置顶窗口之上，但始终排在遮罩下面：

- 在被遮的显示器上，录像里那块仍是黑的。
- 放在没遮的显示器上，它会被录到（这是允许的）。

注意：遮罩不能用 alpha=0 实现完全透明，那样系统会直接忽略这个窗口，截屏又能截到桌面了。

## 实测（2026-11-24，Windows 11，3 块显示器，含 4K 屏）

| 检查项 | 结果 |
|---|---|
| GDI 截屏（BitBlt，微信/QQ 截图一类） | 3 块屏全黑 |
| DXGI 桌面复制（ffmpeg ddagrab，OBS 默认方式一类） | 3 块屏全黑 |
| 遮罩对用户是否透明 | 透明：遮罩下的桌面像素与不开时一致，屏幕上没有任何额外标记 |
| 鼠标穿透 | 正常，点击落在下面的窗口上 |
| 别的程序开启后才弹出的置顶窗口 | 30ms 内已被盖住 |
| 已经显示着的窗口自己设成置顶（不弹出、不抢焦点） | 最晚约 47ms 被盖住 |
| 空闲时 CPU 占用 | 不含宠物：5 秒内 CPU 时间无增长；宠物动画：约单核 1.6% |
| 宠物 | 显示 / 隐藏随开关走、拖动并记住位置、右键菜单、被遮屏幕上录像仍为黑 |
| 热键开 / 关、只遮主显示器、`--exit` 退出 | 正常 |

**没测的**：Windows Graphics Capture（Win11 截图工具、OBS 的"Windows 10"捕获方式、部分会议软件的屏幕共享）。它和 DXGI 走同一个合成标记，预计也是黑的，但最好用你常用的软件亲自试一次。

## 已知局限

- **系统层级更高的界面会露出**：微软拼音输入法的浮窗和候选框、开始菜单都会出现在录屏里，实测确认。它们在系统专门的高层级里，普通程序的窗口盖不上去。Alt+Tab、通知中心大概率也一样。所以防录屏开启期间：
  - 不要用微软拼音打字（第三方输入法的窗口是普通置顶窗口，预计能盖住，未实测）。
  - 不要打开开始菜单。
- **只录单个窗口时不起作用（有意保留）**：OBS 的"窗口捕获"、会议里的"共享指定窗口"、PrintWindow 这类方式直接取那个窗口自己的画面，不经过整屏合成，遮罩挡不住，实测确认。这是有意保留的：有些远程控制、远程协助工具依赖单窗口捕获。录屏时要用"整个屏幕 / 显示器捕获"模式，遮罩才生效。
- **鼠标指针**：很多录屏软件单独采集光标，黑屏上可能还能看到指针移动，需要在录屏软件里关掉"录制光标"。
- **只管画面**：声音照录。
- **软件以外的录制挡不住**：手机拍屏、HDMI 采集卡都录得到。

## 构建

需要 .NET 10 SDK。

```powershell
dotnet publish ScreenCheat.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```
